# What it does:
- This remaps the controls to what I'm used to on PC for my Anbernic RG 34XXSP handheld

# New controls:
- Swapped the 'A' and 'B' button.
- Turbo A is on the 'X' button.
- Turbo B is on the 'L1' button.
- Saving the game is on the 'L3' button (directional click in).
- Loading the game is on the 'R1' button.
- Select has been moved to the 'Y' button (regular select still works).

- You should be able to configure the speed of the turbo but I got it cranked up.
- Very simple mod to give me more familiarity on a handheld.
